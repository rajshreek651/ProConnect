# LINKEDIN CLONE : A SOCIAL MEDIA PLATFORM
#### THIS PROJECT IS BUILT USUING 'NEXT JS'
#### ALSO USES REACT-REDUX INSTEAD OF JUST REACT

#### Nextjs common patterns :-
(1) Search Engine Optimization (SEO)
(2) Server Side Rendering (SSR) --> used when dynamic platforms like here 'LINKEDIN', where things like comment, post, etc, getting updated
(3) Static Side Rendering --> Automative Html file made for 'static site'
(4) api routes --> automatically uses your directory (i.e., just creating index.jsx files in directory and search with '/<directory_name>')

## Project FUGU : A blessing for Web developers, as there's support :- readable stream, zoom video call, OTP, file handling, web authentication, web GPU(Graphic Processing Unit) --> provides web browser at its max capabilities

### Install :-
(1) npx create-next-app@latest : to create 'frontend' folder with 'Nextjs'
(2) for 'backend' : npm install bcrypt cors crypto dotenv express mongoose multer nodemon pdf-creator-node pdfkit
    (i) bcrypt: to encrypt password (for security authorization & authentication)
    (ii) crypto : for 'TOKEN' generation (for security authorization & authentication)
    (ii) cors : for network connection etc.
    (iii) dotenv : for 'process'
    (iv) express : backend framework
    (v) mongoose : for connection with MongoDB
    (vi) multer : for uploading files in their respective destinations
    (v) nodemon : to automatically 'REFRESH' the webpage
    (vi) pdf-creator-node pdfkit : for converting 'linkedin profile to resume pdf'
(3) Insatll 'ES7 + React/Redux/React-Native snippets'
(4) REST client extension
(5) file 'api.http' was made to check 'api endpoints'
